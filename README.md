## 🟡 Game Description 𔓎𔓎𔓎𔓎 ⍩⃝
The Last Waka is a 3D first-person horror maze game inspired by the classic retro game Pac-Man. Trapped in a pitch-black maze patrolled by ghosts, players must navigate through dark corridors using a flashlight and escape the maze safely. To escape, you must explore the map, collect colored pellets, and locate four color-coded generators. Interact with generators by going near one and repairing it, permanently flooding that map sector with ambient light while removing its section's ghost. Successfully repairing all four generators unlocks your escape, but taking hits from ghosts depletes your limited lives and teleports you back to spawn.

## 🟡 Game Controls

| Input | Action |
| :--- | :--- |
| **W / A / S / D** | Move Player |
| **Mouse** | Look / Rotate Camera |
| **Left Shift** | Sprint *(Consumes Stamina)* |
| **E** *(Hold)* | Interact / Repair Generator |
| **Escape** | Pause Game / Unlock Cursor |
